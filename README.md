# Утренняя гимнастика — Gym Timer

Браузерный таймер утренней гимнастики: крупный счётчик повторений, автоматическая
смена подходов и отдыха, зелёный интерфейс в стиле старого монитора.
Исходная версия создана в ChatGPT и перенесена из `gymnastics-timer-v4-final.html`.

## Запуск

Размещённая версия: **[gym.web6hzf4.st](https://gym.web6hzf4.st/)**.

Откройте [`index.html`](index.html) в браузере. Сборка, установка зависимостей
и сервер для обычного запуска не нужны: HTML, CSS и JavaScript находятся в одном файле.
Файл также можно разместить на статическом хостинге.

Таймер работает без интернета. Шрифт Terminus при отсутствии локальной версии
загружается с GitHub; если он недоступен, используется системный моноширинный шрифт.

## Размещение на cr_test

Адрес сайта — **https://gym.web6hzf4.st/**. В DNS зоны `web6hzf4.st` настроена
запись **A**, имя **gym**, значение **5.180.20.102**; TTL можно оставить
**300 секунд** или «Авто».

На сервере нужны Docker, свободные публичные порты 80/443 и SSH-доступ с правами
управления Docker и каталогом `/opt/apps`. Запуск из каталога репозитория:

```bash
# Публикуем или обновляем сайт на его домене.
bash deploy.sh cr_test gym.web6hzf4.st
```

Скрипт загружает текущий `index.html` и запускает контейнер `gym-timer-test`
с Caddy. Для домена Caddy автоматически получает и продлевает сертификат,
перенаправляет HTTP на HTTPS; [условия выпуска сертификата](https://caddyserver.com/docs/quick-starts/https).
Для нового сайта до привязки домена скрипт также принимает `http://IP`;
в этом режиме блокировка сна экрана может быть недоступна.

Повторите ту же команду для обновления страницы. Файлы и сертификаты находятся
в `/opt/apps/gym-timer/test/`; повторный деплой перечитывает настройки без остановки
сервера, контейнер запускается после перезагрузки VM. Исходники релизов сохраняются
в `releases/`, а публично отдаётся только каталог `site/` с `index.html`.
Обновление версии образа Caddy требует пересоздания контейнера с сохранением `data/`.

## Управление

- **Старт** — начать программу с 20 секунд подготовки.
- **Нажатие на экран вне кнопок** — поставить тренировку на паузу и открыть меню.
- **Продолжить** — возобновить отсчёт с места остановки.
- **Назад / Вперёд** — на паузе выбрать соседний подход. Он начнётся с первого
  повторения без подготовительного отдыха после нажатия «Продолжить».
- **Сначала** — после завершения вернуться к стартовому экрану.
- **Клавиатура:** `Enter` или `Пробел` запускают программу со стартового экрана;
  во время тренировки `Пробел` переключает паузу, а `←` / `→` выбирают подход на паузе.

Вверху указаны упражнение и номер подхода. Во время работы крупная цифра показывает
номер повторения, а нижняя шкала задаёт ритм, заполняясь и опустошаясь.
Во время отдыха шкала постепенно убывает; числового обратного отсчёта нет.

## Программа

| Упражнение | Подходы × повторения | Одно повторение | Цикл шкалы |
| --- | --- | --- | --- |
| Руки вперёд | 3 × 10 | 3 с | 3 с |
| Руки в стороны | 3 × 10 | 3 с | 3 с |
| Руки согнуты в локтях | 3 × 10 | 2,5 с | 2,5 с |
| Разведение в стороны | 3 × 10 | 2,5 с | 2,5 с |
| Приседания | 3 × 10 | 2,5 с | 2,5 с |
| Наклоны | 1 × 10 | 8 с | 2 с |

- Подготовка перед началом — **20 секунд**.
- Отдых между подходами одного упражнения — **15 секунд**.
- Отдых между упражнениями — **20 секунд**.
- Всего — **16 подходов, 160 повторений, 12 минут 35 секунд** без ручных пауз и переходов.

Для изменения программы отредактируйте массив `exercises` в `index.html`:
`name` — название, `approaches` — число подходов, `reps` — повторения,
`repMs` — длительность повторения, `pulseMs` — полный цикл шкалы.
Длительности задаются в миллисекундах. Интервалы отдыха находятся рядом:
`INITIAL_BREAK_MS`, `BETWEEN_APPROACHES_MS`, `BETWEEN_EXERCISES_MS`.

## Особенности текущей версии

- Интерфейс адаптируется к размеру экрана, включая телефон.
- При старте и продолжении запрашиваются полноэкранный режим и блокировка сна экрана
  через Screen Wake Lock API. Их доступность зависит от браузера и условий запуска;
  отказ не останавливает таймер. При ручной паузе приложение выходит из полноэкранного режима.
- При задержках кадров таймер учитывает прошедшее время. Для остановки используйте
  ручную паузу: само переключение на другую вкладку не приостанавливает программу.
- Звуковых сигналов, редактора программы в интерфейсе и сохранения прогресса нет.
  Перезагрузка страницы возвращает к стартовому экрану.
